六大功能模块
独立可组合的评估单元
① 格式分布统计
按扩展名统计文件数量、占比、总大小。支持 11 种格式
format_distribution
② PDF 页面类型识别
逐页分析：text / scanned / mixed / empty。多数投票法判定文档级类型
pdf_page_types
③ 文档长度分布
5 级分位数统计 + 5 个长度区间。支持 PDF/DOCX/TXT/MD/HTML 等
length_distribution
④ 重复检测
MD5 精确匹配 + SimHash 近似匹配。大小差异 3x 自动跳过优化
duplicates
⑤ 敏感信息检测
手机号 / 邮箱 / 身份证正则扫描，结果自动脱敏（保留前3后4）
sensitive_info
⑥ 文档分类标签
11 种标签：Text_PDF / Scan_PDF / Mixed_PDF / Needs_OCR / DOCX / Markdown / Short_Doc / Long_Doc / Duplicate / Sensitive / Unsupported
classification
