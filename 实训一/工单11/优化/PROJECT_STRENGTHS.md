# 🌟 招股说明书智能问答系统（含嵌入模型微调） — 项目优点分析

> 从模型微调、检索引擎、多模态能力、工程质量、评估体系五个维度，全面展示本项目的核心亮点。

---

## 一、嵌入模型微调能力 🧠（核心亮点）

### 1.1 端到端微调流水线
系统提供了完整的嵌入模型微调流程，从数据生成到模型训练到效果评估，全自动化：

```
文档 chunks → 自动生成 QA 对 → 训练/评估集划分 → 基线评估 → 微调训练 → 效果对比 → 更新配置
```

这是之前所有工单都不具备的能力，让系统能针对特定文档领域自适应优化嵌入模型。

### 1.2 自动训练数据生成
`DatasetGenerator` 从文档 chunks 中自动提取训练数据：
- **正则模板匹配**：预定义了 11 种针对招股说明书的问题模板（财务、风险、产品、公司信息等）
- **正负样本对**：每个匹配生成 (query, positive, negative) 三元组
- **随机负采样**：从不相关的 chunks 中随机选择作为 hard negative
- 最多生成 500 个 QA 对，自动按 80/20 划分训练集/评估集

无需人工标注，直接从已有文档中自动生成训练数据。

### 1.3 MultipleNegativesRankingLoss
使用 `sentence-transformers` 的 `MultipleNegativesRankingLoss` 作为损失函数：
- 专为检索任务设计，最大化正样本对相似度，最小化负样本对相似度
- batch 内其他样本自动作为负样本，无需显式提供 hard negative
- 在语义检索任务上效果优于 MSE/MarginMSE 等通用损失

### 1.4 手动训练循环
微调采用手动训练循环而非 `model.fit()`，优势是：
- 绕过 `transformers` 版本兼容问题
- 可以自定义每个 batch 的处理逻辑
- 每个 epoch 保存检查点，支持断点续训
- 实时打印 loss，方便监控训练过程

### 1.5 基线 vs 微调对比评估
微调前后都用相同的评估集计算 `Recall@1/3/5` 和 `avg_similarity`，并输出性能对比：
```
Recall@1: 0.6000 → 0.8000 (↑ 0.2000)
Recall@3: 0.8000 → 0.9000 (↑ 0.1000)
```
让微调效果一目了然。

### 1.6 自动更新配置
微调完成后自动备份原 `config.py`（→ `.py.bak`），并将 `EMBEDDINGS_MODEL` 替换为微调后的模型路径。重启系统即生效。

### 1.7 交互式测试
`test_finetune.py` 支持交互式测试模式：用户输入查询，同时展示原始模型和微调模型的 Top3 检索结果，直观对比效果。

## 二、检索引擎优点 🔍

### 2.1 三模式检索引擎
支持 `vector`（向量）、`bm25`（全文）、`hybrid`（混合）三种检索模式，可通过配置或 API 动态切换。

### 2.2 混合检索流水线
`hybrid` 模式实现完整的工业级检索流水线：
```
Query → BM25 召回 + 向量召回 → RRF 融合 → Reranker 精排 → Top-K
```

### 2.3 本地模型支持
支持从本地路径加载模型（`m3e-base`、`bge-reranker-base`），离线环境可用，避免重复下载。

## 三、多模态能力优点 🎨

### 3.1 五种输入方式
文字输入、语音输入、图片上传、图片+文档联合问答、批量处理。

### 3.2 多轮对话 + 流式输出
前端维护对话历史，SSE 流式输出逐字渲染，先推送元数据再推送文本。

### 3.3 PDF 文档管理
支持多 PDF 上传、删除、激活/停用、拖拽上传。

## 四、工程质量优点 📝

### 4.1 清晰的模块化架构
项目分为 8 个独立模块：

| 模块 | 职责 |
|---|---|
| `config.py` | 集中配置管理 |
| `api_server.py` | FastAPI Web 服务 |
| `app_core.py` | 核心问答逻辑 |
| `embedding.py` | 向量化 + FAISS |
| `finetune_full.py` | 嵌入模型微调 |
| `test_finetune.py` | 微调效果测试 |
| `image_processor.py` | 图片理解 |
| `ui_app.py` | Streamlit 前端 |

### 4.2 多级降级策略
- LLM API 不可用 → 本地关键词匹配兜底
- FAISS 检索失败 → 本地余弦相似度检索
- 混合检索失败 → 降级为纯 BM25
- 嵌入模型加载失败 → 哈希向量兜底

### 4.3 丰富的 API 接口
FastAPI 提供 17+ 个 RESTful 接口，覆盖所有功能。

### 4.4 CLI 支持
`finetune_full.py` 支持 `--only-generate`（仅生成数据）和 `--only-evaluate`（仅评估）模式，灵活组合使用。

## 五、评估体系优点 📊

### 5.1 多层次评估
- **RAGAS 评估**（如集成）：Context Precision + Context Recall
- **微调评估**：Recall@1/3/5 + avg_similarity
- **交互式测试**：人工直观对比

### 5.2 自动化评估流水线
`test_finetune.py` 自动加载评估集、编码、计算相似度、输出对比报告。

### 5.3 评估数据持久化
评估集保存为 JSONL 格式，可复现、可分享、可版本管理。
