# 招股说明书智能问答系统 — 用户手册

## 1. 欢迎使用

欢迎使用**招股说明书智能问答系统**！本系统基于 RAG（检索增强生成）技术，能够智能解析招股说明书 PDF 文档，您只需用自然语言提出问题，系统便会自动从文档中检索相关信息并生成准确的回答。系统支持同时加载多个 PDF 文档，并提供**多轮对话**、**流式输出**、中英双语回答、语音输入和图片理解功能。

---

## 2. 系统功能

- 🔍 **智能文档检索**：自动从招股说明书中找到与问题最相关的段落
- 🤖 **AI 答案生成**：基于大语言模型生成准确、简洁的回答
- 💬 **多轮对话**：支持连续追问，系统会结合上下文理解您的问题
- ⚡ **流式输出**：回答像「打字」一样逐步出现，无需等待完整生成
- 📊 **置信度评估**：每条回答附带置信度评分，帮助您判断答案可靠性
- 📚 **参考来源追溯**：显示答案所依据的文档页码、相似度和来源文件
- 🎯 **意图识别**：自动识别问题类别（财务、产品、风险等）
- 💡 **快捷提问**：提供预设问题，一键获取常见信息
- 📄 **多 PDF 管理**：支持同时加载多个 PDF 文档，可动态切换激活状态
- 🖼️ **图片理解**：上传图片（图表、截图等），系统自动分析内容并结合文档回答
- 🎤 **语音输入**：支持语音录入问题（需安装 SpeechRecognition 库）
- 🌐 **中英双语**：支持中文和英文回答

## 3. 快速开始

### 3.1 环境准备

**系统要求**：
- Python 3.8+
- 操作系统：Windows / macOS / Linux

**安装步骤**：

1. **安装 Python 依赖**：
   ```bash
   pip install -r requirements.txt
   ```

2. **配置 API 密钥**（可选，不配置也可使用本地兜底模式）：

   编辑项目目录下的 `.env` 文件：
   ```
   # DeepSeek API（文本问答）
   DEEPSEEK_API_KEY=sk-你的密钥
   DEEPSEEK_API_BASE=https://api.deepseek.com

   # 阿里云百炼 Qwen-VL API（图片理解，可选）
   QWEN_VL_API_KEY=sk-你的密钥
   QWEN_VL_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
   QWEN_VL_MODEL=qwen-vl-plus-latest
   ```

3. **准备 PDF 文档**：

   将您的招股说明书 PDF 文件放入 `data/` 目录。系统默认配置了 PDF 文件：
   - `招股说明书1-无水印.pdf`

   如需修改，在 `config.py` 中编辑 `PDF_FILES` 列表。

4. **运行初始化脚本**（可选）：
   ```bash
   python setup.py
   ```
   该脚本会自动创建所需目录、安装依赖并检查配置。

---

### 3.2 启动系统

系统提供三种使用方式，您可以根据需要选择：

#### 方式一：Web 界面（推荐）

```bash
python api_server.py
```

启动后，在浏览器中访问 **http://localhost:8080** 即可使用。

> **Windows 用户**：也可以直接双击 `run_web.bat` 快速启动。

#### 方式二：命令行交互

```bash
python 1.py
```

启动后进入交互式问答模式，在终端中输入问题即可。

#### 方式三：Streamlit 界面

```bash
python -m streamlit run ui_app.py
```

启动后在浏览器中打开显示的地址（通常为 http://localhost:8501）。

## 4. 使用指南

### 4.1 Web 界面使用

#### 4.1.1 文字提问

1. 在页面底部的输入框中输入您的问题
2. 点击**发送按钮**（或按 `Enter` 键）提交问题
3. 系统会**实时流式输出**回答内容，像打字一样逐步显示
4. 查看回答结果

#### 4.1.2 多轮对话

系统支持上下文记忆的多轮对话，您可以基于之前的回答继续追问：

1. 先提出一个问题，如「公司的主营业务是什么？」
2. 等待回答完成后，继续提问「那这个业务的收入占比是多少？」
3. 系统会自动将之前的对话历史发送给 LLM，实现上下文连贯的问答

> **提示**：系统会保留最近 10 轮对话历史。新建对话可点击左侧边栏的「新对话」按钮。

> **提示**：按 `Shift + Enter` 可以在输入框中换行。

#### 4.1.3 图片问答

1. 点击输入框左侧的 🖼️ **图片按钮**
2. 选择一张图片文件（支持 JPG、PNG、BMP、GIF、WebP 格式，最大 10MB）
3. 图片会显示在输入框上方的预览区
4. （可选）在输入框中输入对图片的问题，例如"这张图表展示了什么？"
5. 点击**发送按钮**提交
6. 系统会先分析图片内容，然后结合文档生成综合回答
7. 回答中会包含图片分析结果和文档检索结果

**适用场景**：
- 📈 上传招股说明书中的图表，让系统解读数据趋势
- 📋 上传表格截图，提取关键数据
- 📝 上传含文字的图片，进行 OCR 提取和分析

> **提示**：点击聊天中的图片缩略图可以放大查看，按 ESC 键关闭大图。

#### 4.1.4 语音输入

1. 点击输入框左侧的 🎤 **语音按钮**
2. 说出您的问题
3. 系统自动将语音转换为文字
4. 确认文字后点击发送

> **注意**：语音输入需要安装 `SpeechRecognition` 和 `pydub` 库。

#### 4.1.5 查看回答

每条回答包含以下信息：

| 信息 | 说明 |
|------|------|
| **回答内容** | 系统根据文档生成的答案，以流式方式逐步显示 |
| **置信度** | 答案的可靠程度（百分比），数值越高越可靠 |
| **参考来源** | 答案所依据的文档页码、相似度及来源文件 |

#### 4.1.6 快捷提问

页面提供预设问题按钮，点击即可快速提问：

- **公司的主营业务是什么？** — 了解公司的核心业务
- **公司面临的主要风险因素有哪些？** — 了解公司面临的主要风险
- **公司最近三年的营业收入是多少？** — 查询公司的财务数据
- **公司的发展战略和未来规划是什么？** — 了解公司的发展方向

#### 4.1.7 回答操作

对每条回答，您可以：

- 📋 **复制**：一键复制回答内容到剪贴板
- 🔄 **重试**：对同一问题重新提问
- 👍👎 **反馈**：对回答质量进行评价

#### 4.1.8 文档管理

点击左侧边栏的**文档管理**按钮，可以：

- **上传 PDF**：拖放或点击选择 PDF 文件上传
- **激活/停用**：勾选或取消勾选 PDF 文件，控制哪些文档参与检索
- **删除文件**：删除不需要的 PDF 文件
- **重建索引**：手动触发索引重建

#### 4.1.9 语言切换

点击左侧边栏的**语言切换**按钮，可在中文和英文界面之间切换。

### 4.4 多 PDF 文档管理

系统支持同时加载多个 PDF 文档进行索引和检索。

#### 4.4.1 添加 PDF 文件

将 PDF 文件放入 `data/` 目录即可。也可以通过 Web 界面上传：
- 在文档管理弹窗中拖放或选择 PDF 文件
- 调用 `POST /api/upload-pdf` 接口上传文件

#### 4.4.2 查看 PDF 列表

通过 Web 界面的文档管理弹窗查看所有已加载的 PDF，或通过 API：
```
GET /api/pdfs
```

#### 4.4.3 切换激活的 PDF

在文档管理弹窗中勾选/取消勾选 PDF 文件，或通过 API：
```
POST /api/set-active-pdfs
{
  "pdf_names": ["招股说明书1-无水印.pdf"]
}
```

设置后系统会自动重建索引。传入 `null` 可恢复全部激活。

#### 4.4.4 删除 PDF 文件

在文档管理弹窗中点击删除按钮，或通过 API：
```
DELETE /api/pdfs/招股说明书2.pdf
```

删除后系统会自动重建索引。

## 5. 提问技巧

### 5.1 提问建议

为了获得更准确的回答，请参考以下建议：

| 建议 | 好的提问 | 不好的提问 |
|------|---------|-----------|
| **具体明确** | "公司2023年的净利润是多少？" | "公司怎么样？" |
| **指明时间** | "公司最近三年的营业收入分别是多少？" | "收入是多少？" |
| **聚焦单一主题** | "公司的主要客户有哪些？" | "客户和供应商和产品都是什么？" |
| **使用专业术语** | "公司的资产负债率是多少？" | "公司欠了多少钱？" |

### 5.2 常见问题类型

您可以就以下方面向系统提问：

- **财务信息**：营业收入、净利润、资产负债、现金流等
- **公司概况**：主营业务、组织结构、管理团队、股东信息等
- **产品服务**：主要产品、服务范围、技术优势等
- **风险分析**：经营风险、市场风险、政策风险等
- **发展战略**：未来规划、投资方向、发展目标等
- **市场分析**：行业状况、竞争格局、市场份额等

### 5.3 复杂问题处理

如果您的问题涉及多个方面，建议分步提问：

```
❌ 公司的财务状况、主要产品和面临的风险分别是什么？
✅ 公司2023年的主要财务指标是什么？
✅ 公司的主要产品有哪些？
✅ 公司面临的主要风险因素有哪些？
```

## 6. 理解回答结果

### 6.1 置信度解读

| 置信度范围 | 含义 | 建议 |
|-----------|------|------|
| 70% - 100% | 高度可靠 | 可以信赖，建议核实关键数据 |
| 40% - 70% | 中等可靠 | 建议查看参考来源确认 |
| 0% - 40% | 较低可靠 | 建议重新表述问题或查看原始文档 |

### 6.2 参考来源

每条回答都会列出参考来源，包含：
- **页码**：答案所依据的文档页码
- **相似度**：该段落与问题的相关程度（百分比）
- **来源文件**：该段落来自哪个 PDF 文件

> **提示**：对于重要数据（如财务数字），建议对照原始 PDF 文档进行核实。

### 6.3 回答局限性

- 系统严格依据提供的 PDF 文档回答，如果文档中没有相关信息，系统会明确告知
- 如果 PDF 文档质量较差（如扫描件），可能影响文本提取和回答质量
- AI 生成的回答可能存在理解偏差，重要决策请以原始文档为准
- 图片分析依赖 Qwen-VL 模型，复杂图表的解读可能存在误差

## 7. 常见问题解答 (FAQ)

### Q1: 首次运行为什么很慢？

**A**: 首次运行时，系统需要：
1. 读取所有激活的 PDF 文档并提取文本
2. 将文本拆分为多个片段
3. 计算每个片段的向量表示
4. 构建向量索引

这个过程可能需要几分钟，取决于 PDF 文件大小和数量。完成后索引会保存到磁盘，后续运行会直接加载，速度会快很多。

### Q2: 提示"PDF文件未找到"怎么办？

**A**: 请检查：
1. PDF 文件是否放在 `data/` 目录下
2. `config.py` 中的 `PDF_FILES` 列表是否包含该文件名
3. 文件名是否完全匹配（包括中文字符）

### Q3: 没有配置 API Key 能使用吗？

**A**: 可以。系统在没有 DeepSeek API Key 时会自动切换到本地兜底模式，直接返回文档中的相关片段作为参考。但回答质量会有所下降。图片理解功能需要单独配置 Qwen-VL API Key。

### Q4: 如何更换知识库文档？

**A**: 
1. 将新的 PDF 文件放入 `data/` 目录
2. 在 `config.py` 中更新 `PDF_FILES` 列表
3. 删除 `data/faiss_index/` 目录（清除旧索引）
4. 重新启动系统，它会自动为新文档构建索引

也可以通过 Web 界面管理：
- 使用文档管理弹窗上传新文件
- 勾选/取消勾选文件设置激活列表
- 点击"重建索引"按钮

### Q5: 答案不准确怎么办？

**A**: 请尝试：
1. 重新表述问题，使用更具体的关键词
2. 将复杂问题拆分为多个简单问题
3. 查看参考来源，确认检索到的文档段落是否正确
4. 调整检索文档数（Streamlit 界面侧边栏可调）

### Q6: 系统支持哪些语言？

**A**: 系统主要支持**中文**，同时支持英文等其他语言。嵌入模型使用的是多语言模型（`paraphrase-multilingual-MiniLM-L12-v2`），具备跨语言理解能力。Web 界面和命令行默认使用中文回答，API 接口支持通过 `lang` 参数切换为英文回答。

### Q7: 多轮对话是如何工作的？

**A**: 系统会自动将您最近 10 轮的对话历史（包括您的问题和系统的回答）发送给大语言模型，使其能够理解上下文。例如，您可以先问「公司的主营业务是什么？」，然后追问「那收入占比是多少？」，系统会知道「那」指的是主营业务。如果需要重新开始，点击左侧边栏的「新对话」按钮即可。

### Q8: 流式输出是什么意思？

**A**: 流式输出是指系统的回答会像「打字」一样逐字逐句地显示在屏幕上，而不是等待全部生成完毕后一次性展示。这样您可以更早看到回答内容，提升交互体验。流式输出通过 SSE（Server-Sent Events）技术实现。

### Q9: 如何提高系统性能？

**A**: 
- 确保安装了 `faiss-cpu` 和 `sentence-transformers`，避免使用兜底模式
- 如果 PDF 文件很大，可以适当增大 `CHUNK_SIZE` 减少分块数量
- 确保系统有足够的内存（建议 4GB 以上）

### Q10: 网络错误怎么办？

**A**: 如果出现网络错误：
1. 检查网络连接是否正常
2. 确认 DeepSeek API 服务是否可用
3. 系统会自动切换到本地兜底回答，不会完全无法使用

### Q11: 如何使用语音输入？

**A**: 语音输入功能需要安装额外依赖：
```bash
pip install SpeechRecognition pydub
```

安装后，在 Web 界面中点击 🎤 语音按钮即可录制问题，系统会自动将语音转换为文字。

### Q12: 如何使用图片理解功能？

**A**: 图片理解功能需要配置阿里云百炼 Qwen-VL API Key：

1. 在 `.env` 文件中配置：
   ```
   QWEN_VL_API_KEY=sk-你的密钥
   ```

2. 在 Web 界面中：
   - 点击 🖼️ 图片按钮选择图片
   - 可选：输入对图片的问题
   - 点击发送，系统会分析图片并结合文档回答

3. 支持的图片格式：JPG、PNG、BMP、GIF、WebP（最大 10MB）

### Q13: 图片分析结果中有很多符号怎么办？

**A**: 系统已自动过滤模型输出中的 `#`、`**`、`---` 等无意义符号。如果仍有问题，请尝试重新上传图片或调整提问方式。

### Q14: 如何同时使用多个 PDF 文件？

**A**: 将所有 PDF 文件放入 `data/` 目录，并在 `config.py` 的 `PDF_FILES` 列表中添加文件名。系统默认会索引所有文件。如需只使用部分文件，可通过文档管理弹窗或 `POST /api/set-active-pdfs` 接口设置激活列表。

|------|------|
| `1.py` | 命令行主程序 |
| `config.py` | 全局配置（含多 PDF 文件列表、Qwen-VL 配置） |
| `document_loader.py` | PDF 文档加载与分块（支持多 PDF） |
| `embedding.py` | 向量嵌入与检索（FAISS / 本地兜底） |
| `query_processor.py` | 查询理解（意图识别、分解、实体提取） |
| `llm_agent.py` | LLM 代理与回答生成（支持中英双语） |
| `image_processor.py` | 图片处理模块（基于 Qwen-VL 模型） |
| `app_core.py` | 共享初始化逻辑（懒加载、多 PDF 管理） |
| `api_server.py` | Web API 服务（含 PDF 管理、图片处理和语音识别接口） |
| `ui_app.py` | Streamlit 界面（含语音输入） |
| `setup.py` | 项目初始化 |
| `test_system.py` | 系统集成测试 |
| `local_test.py` | 本地模块测试 |
| `.env` | 配置文件（API Key 等） |
| `requirements.txt` | Python 依赖清单 |
| `run_web.bat` | Windows Web 启动脚本 |
| `run.bat` | Windows 命令行启动脚本 |
| `data/` | 存放 PDF 文件、索引数据和上传的图片 |
| `data/images/` | 上传的图片存储目录 |
| `frontend/` | FastAPI 前端静态资源 |
| `results/` | 批量查询结果输出目录 |
