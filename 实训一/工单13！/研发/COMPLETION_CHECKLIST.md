## 🛠️ 故障排查

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| PDF找不到 | 路径错误 | `mkdir data && cp pdf data/` |
| API失败 | 密钥错误 | 检查config.py API_KEY |
| 答案不准 | 参数不佳 | 调整TOP_K和TEMPERATURE |
| 速度慢 | 首次初始化 | 等待完成，后续会快速缓存 |
| 内存不足 | 文件太大 | 减小CHUNK_SIZE |

### 诊断工具
```bash
python test_system.py --api         # 测试API
python test_system.py --config      # 测试配置
python test_system.py --query       # 测试Query处理
```
