## 问答流程详解

### 第一阶段：系统初始化

```
START
  ↓
检查索引是否存在？
  ├─ YES → 加载已存在的索引（快速）
  └─ NO → 进行第一次初始化
           ├─ 加载PDF文件
           ├─ 分割成文本块
           ├─ 向量化每个块
           ├─ 构建FAISS索引
           └─ 保存到磁盘
              ↓
系统就绪，进入问答模式
```

### 第二阶段：单个问答流程

```
用户输入问题
  ↓
[Query理解阶段]
  ├─ 意图识别
  │  └─ 分类（财务、产品、风险等）
  ├─ 问题分解
  │  └─ 拆分复杂问题
  └─ 实体抽取
     └─ 提取关键信息

  ↓
[检索阶段]
  ├─ 向量化查询
  ├─ FAISS搜索
  │  └─ 找到K个最相似的文本块
  └─ 排序和过滤
     └─ 按相似度排序

  ↓
[生成阶段]
  ├─ 构建上下文
  │  └─ 融合检索到的文本
  ├─ 构建消息列表
  │  ├─ 系统提示
  │  ├─ 历史对话（最近10轮）
  │  └─ 当前问题 + 参考文档
  ├─ 调用LLM API
  │  ├─ 同步模式：一次性返回完整答案
  │  └─ 流式模式：逐块返回文本（SSE）
  └─ DeepSeek生成答案

  ↓
[后处理]
  ├─ 计算置信度
  ├─ 提取来源信息
  └─ 返回完整结果

  ↓
展示答案 + 置信度 + 来源
```

## 核心模块工作原理

### 1. Query理解模块 (query_processor.py)

**目的**：理解用户的真实意图

**工作流程**：
```
输入问题
  ↓
意图识别
  ├─ 匹配关键词
  ├─ 确定问题类别
  └─ 返回意图类型
  
问题分解
  ├─ 检测连接词
  ├─ 拆分为子问题
  └─ 递归处理

实体抽取
  ├─ 时间表达式提取
  ├─ 数字/金额提取
  └─ 关键词提取

输出：{"intent", "sub_queries", "entities"}
```

**识别的意图类型**：
- `财务信息`：收入、利润、资产等
- `公司信息`：组织、管理、股东等
- `产品服务`：产品类型、功能等
- `风险分析`：风险因素、挑战等
- `发展战略`：规划、目标等
- `市场分析`：竞争、规模等
- `一般信息`：其他问题

### 2. 文档处理模块 (document_loader.py)

**目的**：从PDF中提取和处理文本

**工作流程**：
```
PDF文件
  ↓
页面提取
  ├─ 按页读取
  ├─ 提取文本内容
  └─ 记录页码

文本分块
  ├─ 按大小分割
  ├─ 保持重叠
  └─ 保存元数据

输出：文本块列表
```

**参数说明**：
- `CHUNK_SIZE=800`：每块800字符
- `CHUNK_OVERLAP=100`：块间重叠100字符
- 重叠的作用：防止关键信息被分割

### 3. 向量检索模块 (embedding.py)

**目的**：快速找到相关文本

**工作流程**：
```
输入：查询文本

向量化
  ├─ 加载模型
  ├─ 编码查询
  └─ 得到向量

检索（FAISS）
  ├─ 计算距离
  ├─ 找K个最近邻
  └─ 返回结果

相似度转换
  ├─ L2距离 → 相似度
  ├─ 范围0-1
  └─ 高分=相关

输出：排序的相关段落
```

**FAISS索引优势**：
- ✅ 快速：O(log N)时间复杂度
- ✅ 高效：支持大规模数据
- ✅ 准确：精确近邻搜索

### 4. LLM生成模块 (llm_agent.py)

**目的**：基于检索结果生成自然语言答案

**工作流程**：
```
检索结果
  ↓
上下文融合
  ├─ 组织文本块
  ├─ 添加来源标记
  └─ 格式化为上下文

提示词构建
  ├─ 系统提示
  ├─ 参考文档
  ├─ 用户问题
  └─ 任务指令

API调用（DeepSeek）
  ├─ 构建请求
  ├─ 设置参数
  │  ├─ max_tokens=1000
  │  └─ temperature=0.7
  └─ 获取响应

置信度计算
  ├─ 文档数量权重
  ├─ 最高相似度权重
  └─ 综合评分

输出：答案 + 置信度 + 来源
```

**温度参数影响**：
- `temp=0.0`：确定的、一致的答案
- `temp=0.5`：平衡
- `temp=1.0`：随机的、多样化答案

## 性能优化要点

### 检索优化
```
问题 → 低准确率
解决方案：
  1. 增加TOP_K (5→7)
  2. 调整CHUNK_SIZE (800→600)
  3. 降低SIMILARITY_THRESHOLD (0.3→0.2)
```

### 生成优化
```
问题 → 答案不准确
解决方案：
  1. 调整temperature (0.7→0.3)
  2. 增加MAX_TOKENS (1000→1500)
  3. 优化提示词模板
```

### 速度优化
```
问题 → 响应慢
解决方案：
  1. 减少TOP_K (5→3)
  2. 增加SIMILARITY_THRESHOLD (0.3→0.5)
  3. 使用GPU加速FAISS
```

### 成本优化
```
问题 → API调用过多
解决方案：
  1. 减少MAX_TOKENS
  2. 增加缓存
  3. 批量处理
  4. 增加SIMILARITY_THRESHOLD过滤
```
