# 🌟 智能文档问答系统 — 项目优点分析

> 从知识图谱、RAG 能力、语音交互、工程质量、用户体验五个维度，全面展示本项目的核心亮点。

---

## 一、知识图谱能力优点 🕸️（核心亮点）

### 1.1 LLM 驱动的实体关系抽取
系统使用小米 MiMo 大模型从文档文本中自动抽取实体关系三元组 `(主体, 关系, 客体)`。相比传统 NLP 工具（如 spaCy NER），LLM 抽取的优势是：
- 能理解复杂语义关系，而非仅匹配模式
- 对中文金融文档的实体识别效果好
- 可通过 Prompt 灵活控制抽取粒度和类型

### 1.2 批量合并 + 并发调用
知识图谱构建采用了高效的处理策略：
- **批量合并**：将多个 chunk 合并为一次 API 调用（`KG_BATCH_SIZE=3`），减少 API 请求次数
- **并发执行**：使用 `ThreadPoolExecutor`（max_workers=3）并发处理多个批次
- **失败降级**：批量抽取失败时自动回退到单条处理

这种设计将知识图谱构建速度提升了约 3 倍。

### 1.3 交互式可视化
使用 Pyvis 生成交互式知识图谱 HTML：
- 基于 forceAtlas2Based 物理引擎，节点自动布局
- 支持拖拽、缩放、悬停查看详情
- 有向边显示关系方向，不同颜色区分实体类型
- 直接嵌入 Streamlit 页面，无需跳转

### 1.4 NetworkX 图结构
使用 NetworkX 有向图（`DiGraph`）存储知识图谱：
- 支持节点/边属性扩展
- 可计算图论指标（度中心性、最短路径等）
- 为后续图查询、推理预留了扩展空间

### 1.5 统计面板
知识图谱 Tab 展示关键统计：实体节点数、关系边数、三元组数量，并提供三元组文本查看功能。

## 二、RAG 能力优点 🔍

### 2.1 完整的 RAG 流水线
系统实现了标准的 RAG（Retrieval-Augmented Generation）流程：
```
PDF → 文本提取 → 分块 → 向量化 → FAISS 索引 → 相似度检索 → LLM 生成
```

### 2.2 高质量中文 Embedding
使用 `bge-base-zh-v1.5`（BAAI 出品）作为嵌入模型：
- 专为中文优化，在中文语义相似度任务上表现优秀
- 自动检测 GPU/CPU，有 GPU 时自动使用 CUDA 加速
- 批量编码（batch_size=64），大幅提升向量化速度
- 归一化嵌入（normalize_embeddings=True），提升余弦相似度计算准确性

### 2.3 智能文本分块
使用 LangChain 的 `RecursiveCharacterTextSplitter`：
- 分隔符优先级：段落 → 句子 → 字符，保证语义完整性
- chunk_size=800 + chunk_overlap=100，在块大小和上下文连续性之间取得平衡
- 中文标点感知（`。！？` 等作为分隔符）

### 2.4 多轮对话记忆
`RAGChain` 维护对话历史（最近 3 轮），每轮自动携带上下文：
- 用户可以追问"它是什么时候成立的？"而不需要重复主语
- 历史消息通过 `messages` 数组传递给 LLM

### 2.5 来源追溯
每个答案附带检索来源（相似度分数 + 文本片段），用户可验证答案的可信度。

## 三、语音交互优点 🎤

### 3.1 双后端降级策略
语音识别模块设计了两级降级：
1. **优先**：本地 Whisper 模型（离线可用、无 API 费用）
2. **备选**：OpenAI 兼容 API（如 MiMo 的语音接口）

无论哪种后端，对外接口统一为 `transcribe(audio_path)`。

### 3.2 自动语言检测
Whisper 设置 `language=None`，自动检测输入语言，支持中英文混合语音。

### 3.3 可配置模型大小
通过 `WHISPER_MODEL_SIZE` 配置项，可在 tiny/base/small/medium/large 之间选择，在识别精度和资源消耗之间灵活权衡。

## 四、工程质量优点 📝

### 4.1 模块化设计
项目分为 6 个独立模块，职责清晰：

| 模块 | 职责 |
|---|---|
| `config.py` | 集中配置管理 |
| `pdf_processor.py` | PDF 处理 + 向量化 |
| `rag_chain.py` | RAG 检索 + 生成 |
| `knowledge_graph.py` | 知识图谱构建 + 可视化 |
| `speech.py` | 语音识别 |
| `app.py` | Streamlit 前端 |

每个模块可独立测试和替换。

### 4.2 GPU 自动检测
`PDFProcessor` 自动检测 CUDA 可用性，有 GPU 时自动使用，无需手动配置。

### 4.3 Session State 管理
Streamlit 的 `session_state` 管理所有状态：PDF处理器、RAG链、知识图谱、对话历史、主题设置。页面刷新不丢失状态。

### 4.4 配置集中化
所有可调参数集中在 `config.py`：API 密钥、模型路径、分块参数、检索参数、知识图谱参数。修改一处即可全局生效。

## 五、用户体验优点 🎨

### 5.1 深色/浅色主题切换
一键切换深色和浅色模式，所有组件（侧边栏、对话气泡、输入框、卡片、知识图谱面板）全部适配主题色。

### 5.2 极简界面设计
- 780px 居中布局，聚焦核心内容
- 欢迎页面展示功能卡片（文档问答、中英文支持、知识图谱、来源追溯）
- 隐藏 Streamlit 默认的菜单/页脚/页头

### 5.3 对话气泡样式
- 用户消息：右对齐圆角气泡
- 助手消息：带标签的文本块，底部细线分隔
- 来源信息：左侧竖线高亮的引用块

### 5.4 侧边栏控制面板
侧边栏集成所有操作：主题切换、状态显示、PDF 上传、知识图谱构建、清除对话。布局紧凑，操作直观。
